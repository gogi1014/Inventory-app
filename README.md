Inventory Management System
A full-stack web application designed to manage warehouse inventory, track stock levels, and generate reports. Built with a focus on clean code and MVC (Model-View-Controller) architecture.

✨ Features
Product Management: Full CRUD (Create, Read, Update, Delete) operations for inventory items.

Real-time Statistics: Dashboard showing total products, out-of-stock items, and inventory value.

PDF Export: Generate professional PDF reports of the current inventory using jsPDF.

Search & Filter: Quickly find products by name or SKU.

🛠️ Technology Stack
Frontend: React.js, Axios (for API calls), Tailwind CSS/CSS.

Backend: Node.js, Express.js.

Database: MySQL.

Architecture: MVC (Model-View-Controller) pattern for scalability.

🏗️ Project Structure
The project is divided into two main parts:

/client: The React frontend (Vite-based).

/server: The Node.js backend with Express routes, controllers, and database models.
